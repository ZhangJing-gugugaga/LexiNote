# 知萤结构化学习笔记构建指南 (`lexinote-study-note`)

## 一、适用场景
当用户希望针对某个学科主题、代码技术或课堂速记生成高质量学习笔记时，使用本 Skill 将内容沉淀为知萤 `study` / `pro` 级别的结构化笔记。

## 二、标准学习笔记结构模板
创建或重构学习笔记时，请将 `noteType` 设为 `"study"`、`editorLevel` 设为 `"pro"`，并采用以下结构：
1. **Frontmatter 属性与多级标签**：
   - 标签建议：`#学习/<学科>`、`#复习`
   - 属性建议：`category: 学习笔记`、`status: 精读中`
2. **核心导读框 (`> [!NOTE]`)**：
   - 在正文顶部用 2~3 句话概括本章核心概念与学习目标。
3. **层次化章节 (`##` / `###`)**：
   - 使用清晰的二级、三级标题，关键定义使用 `==高亮语法==` 标记。
   - 涉及数学/算法复杂度时使用 `$$...$$` 公式块；涉及代码时使用带语言标识的代码块。
4. **知识关联 (`[[双链]]`)**：
   - 先调用 `search_notes` 查找知识库内已有的前置或关联笔记，在文末「关联知识」章节用 `[[笔记标题]]` 建立双向链接。
5. **费曼自测与行动项 (`- [ ]`)**：
   - 在文末生成 2~3 道主动回忆自测题（`- [ ] 问题...`）。
6. **配套思维导图**：
   - 笔记保存后，可主动调用 `manage_mindmap` (`action: "convert_from_note"`) 生成配套思维导图，帮助用户建立全局视觉记忆。
